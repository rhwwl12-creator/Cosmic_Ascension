### 1.1 세계 (입력 없는 판, 20,000틱)

'전부' = #68 + #71 + 전조 1e-4 + 둘째 업적 + 첫 위기. 목표(`docs/40` §9.3, B의 종료 조건 '±30%'): 0.3 미만 < 25%, 반란의 몫 25~40%, 주장 정착률 40~60%.

읽은 것:
1. **'회복만 넣으면 주장 정착률이 떨어진다'는 짐작(#68)은 회복 0.001에서는 틀렸다**(18% → 17%). 0.002에서는 맞다(#71과 함께 42% → 22%). 회복이 영향권 곁의 소모(틱당 0.002 × P)를 넘으면 주장을 받은 백성이 무너지지 않아 구호가 끝까지 간다. 그래서 회복은 소모보다 작은 0.001이다. 0.0015는 0.001보다 나은 것이 없다.
2. #71만 넣으면 안정도가 더 나빠진다(영향권이 자라 소모를 받는 백성이 는다). 둘을 함께 넣는다(기본값 그대로).
3. 반란 해결의 상승은 0.1과 0.2가 같다. 0.1로 둔다.
4. 0.3 미만이 여전히 33%인 것은 영향권 곁에서 소모(최대 틱당 0.004)를 받는 백성이다. 회복을 소모보다 크게 하면 주장이 서지 못한다(1). 칙령의 유지비·철야(B2)와 영압 카드(B4)가 이 자리의 손잡이다 — MVP에서는 이 값으로 둔다.
5. **승인된 둘째 업적(정착 3 ∧ 공학 0.5)은 AI의 T2→T3를 거의 모두 600틱(정착 둘에 걸리는 시간)으로 만든다**(사분위 600·600·700, T3 중앙값 6,400 → 2,000). 연구는 태어날 때부터 쌓이고 기본 중점(0.25)에서 공학 0.5는 약 1,330틱이라 T2에 오를 때 이미 차 있다. 공학 1.0이면 AI T3 중앙값이 2,700이고, 통치자는 '지혜로운 마음'에서 무엇을 골랐는지로 갈린다(아래 1.2).
6. 입력 없는 그릇의 폐위는 '전부'에서 8판(지금 4판)이다. 회복은 그것을 없애지 않는다 — #71로 영향권이 자라 T1에 머무는 그릇이 소모를 받기 때문이다. `Sim.PhaseTwoExit`의 시드 7 블록은 다시 잰다.

## 2. 첫 위기의 보장 (위기 단계 ⓒ의 끝 — 규칙 4의 다섯째 단계 안)

```cpp
// FCosmicRulesDef (Data/CosmicDefinitionRows.h) - 끝에 둘
// The first crisis (section 2.4 first ten minutes, 16 #91): at this tick every people's capital receives
// FirstCrisisHazard, after the draw and the capital rule of the crisis stage. 0 = none. Start value 150 (2:30 at x1).
UPROPERTY(EditAnywhere) int32 FirstCrisisTick = 150;
// A Draw row's tag (Hazard.*): the claim rule's and the capital rule's rows are refused (an error line, nothing placed).
UPROPERTY(EditAnywhere) FGameplayTag FirstCrisisHazard; // data: Hazard.AIAwakening
```

- `State.Tick == FirstCrisisTick`이면 Civs 배열 순서로 백성마다 수도(소유 ∧ 정착)에 그 태그의 행을 `CosmicHazards::Place`로 놓고 `FollowUpNotes`(발생 줄과 행의 `OutbreakRow`). 수도의 슬롯이 이미 찼으면 넘긴다 — 그 자리의 위기가 그 백성의 첫 위기다. **추첨 없음**(놓는 길은 `Place` 하나 그대로, 규칙 13).
- 모든 백성이 같은 규칙을 받는다(2026-10-18 결정, 완화 ⑥ '수치 이점 0'). 첫 생애만 받는 정해진 위기가 아니므로 #91과 맞는다. 다스리는 백성에게는 같은 틱에 위기 청원('깨어난 기계')이 오고 자동 정지가 선다. 둘째 생애(Phase 4b)의 첫 10분은 그때 다시 본다.
- 왜 Standing 이벤트 행(+ `SpawnHazard`)이 아닌가: ① 한 번만 나게 하려면 창 조건(`GalaxyTickReached` 같은 것)이 새로 든다 ② 행의 줄과 위기의 발생 줄, 두 줄이 같은 일을 말한다 ③ 수도 슬롯이 차 있으면 위기 없이 행의 줄만 남는다. `Placed` 열거자는 효과로만 놓이는 위기 행(방문·징조)이 올 때 더한다 — 지금 그런 행이 없다.
- 시각 150은 비전 문서의 '2:30 첫 Hazard(AI 각성, 모성계)'다. 각성의 카운트다운 150틱이 끝나는 300이 '5:00 결과'다.

## 3. 안정도 회복 (#68 — 경제 단계, 인구 회복 바로 뒤)

```cpp
// FCosmicRulesDef - 끝에
// Stability comes back toward the resting level (section 4.1, 9.3 'natural convergence', 16 #68): each tick, before the
// income, a people below StabilityRestingLevel rises by this much and stops there; above it nothing changes (what cards
// and events raised stays). 0 or below, or not a number: no recovery. Start value - below the drain beside a fallen
// sphere (0.002 x P), so that a claimed people still bends (measured: 0.002 brings the claims' settlement rate to 22%).
UPROPERTY(EditAnywhere) float StabilityRecoveryPerTick = 0.001f;
UPROPERTY(EditAnywhere) float StabilityRestingLevel = 0.6f;
```

- 순서: 인구 회복 → **안정도 회복** → 수입 → 틱당 원천(영압의 소모) → 비축. 같은 틱의 `LowStabilityTicks` 셈에 든다(경제 단계 끝에 센다 — `docs/21`의 '귀결 셋'에 한 구절 더한다).
- 아래에서만 오른다: '인구 회복과 같은 꼴'(#68)이고, 위에서 끌어내리면 카드의 +0.15가 150틱 만에 사라진다.
- 데이터: `crisis_rebellion.OnResolveEffects = [ChangeStability +0.1]`(R·AI의 해결이 모두 `CosmicHazards::Resolve`를 지난다). 넘김으로 끝난 반란은 오르지 않는다.
- 사회 연구가 회복을 올리는 것(`systems.md` §5.4 표)은 Phase 4.

## 5. 전조 확률(#72)과 T2→T3 둘째 업적

- 데이터: `crisis_pre_supernova.SpawnChancePerTick` 5e-5 → **1e-4**(조건 `CivTierAtLeast 2` 그대로). 30판 20,000틱의 전조: 897 → 약 1,900.
- 조건 하나를 `EConditionType` 끝에 더한다:

- 행 `feat_three_worlds`(2026-10-18 승인 이름 — 행 이름은 세이브의 `CompletedFeats`에 남아 배포 뒤 동결): Ruler, T2 → T3, 조건 `CivSettledSystemsAtLeast 3` ∧ `CivResearchAtLeast Engineering` **1.0**(승인안은 0.5 — 1.1의 5 때문에 바꾸기를 권한다), 대가 없음. 제목과 줄은 가칭(서사 규칙 11 — 천체의 수를 서술에 쓰지 않는다):
  - 제목 '여러 별의 살림', 신화 서술 "여러 별에 집을 둔 백성은 원인과 결과가 별 사이로 이어지는 것을 본다."
  - 줄 셋: "{Civ}|hpp(이,가) 인과의 칸에 올랐다. 그들의 집은 이제 {HomeSystem} 밖에도 있다." / "{HomeSystem}에서 놓은 길이 다른 별의 집들로 이어졌다. {Civ}|hpp(은,는) 원인과 결과의 결을 읽기 시작했다." / "{Civ}의 살림이 여러 별에 걸쳤다. 그들은 이제 이곳에서 한 일이 먼 별에서 돌아오는 것을 안다."
- 스키마: 조건의 값(정수 1 이상). `Data.Integrity`: 업적 행의 `CivSettledSystemsAtLeast`는 그 행 `RequiredTier`의 `RealmCapByTier`를 넘지 않는다(로드맵 '업적이 그 칸의 보유 상한보다 많은 성계를 요구하지 않는지').
- AI는 T2에서 짓는 것이 없고(`Choices` 그대로) `MaySettle`로 상한 3까지 정착해 이 업적에 닿는다. 정착은 지금처럼 정착을 시작할 수 있는 백성마다 1회 뽑는다.
- **다음 칸 표시**(`UI/CosmicNextRung`, 표현 계층): 지금은 사전순 첫 행만 보인다 — T2에서는 '초신성 안정화'만 보여 저절로 서는 위기를 기다리라는 말이 된다. 그 칸의 판정 행을 모두 보인다(T2에서 둘). 부분 종류 `Realm`(정착한 성계 n/3 — UI 라벨이라 수를 쓴다)을 더한다.

## 6. 커맨드렛의 통치자 정책과 '결정'의 셈 (A-3a — `Tests/CosmicBalanceCommandlet`)

- 인자: `-Answer=0|1`(1 = 카드가 온 틱에 답한다: (답한 수 mod 선택지 수)번째부터 비축으로 낼 수 있는 첫 선택지 — 한 판에서 모든 선택지를 돌아가며 고른다), `-Build=0|1`(1 = 프로젝트 키 `StartNextMegaproject`를 거절될 때까지: 그 백성의 대응·다음 업적의 건설, 없으면 첫 정착 대상), `-Rules=Name:Value;…`(이 판에서만 DT_Rules 칸을 바꾼다 — 노브를 데이터에 적기 전에 잰다. 값은 데이터 임포터처럼 읽는다). **기본값은 모두 끔**이라 지금 판의 세계(`RunHeadless(Ticks)`)와 기준값이 그대로다.
- 순서: 한 틱(`RunHeadless(1)`) → 정책의 입력(답, 그다음 프로젝트) → 위기와 줄의 셈. 답의 줄은 그 틱의 것으로 세고, 답이 끝낸 위기는 그 틱에 끝난 것으로 센다.
- 로그 여섯째 줄 `CosmicBalance ruler:` — 온 카드, 받아들인 답, 시작한 프로젝트, **결정**(= 받아들인 답(성공·실패. 거둬진 카드는 빼고) + 시작한 프로젝트(정착 포함). 연구 중점 프리셋(MVP ⑦)이 오면 그 바꿈도 센다)과 600·6,000틱까지의 결정·말해진 줄, 다스리는 백성이 T2·T3에 오른 틱.
- `run_checks.ps1 -Tier full`에 시드 42 · 3,000틱 · `-Answer=1 -Build=1` 판을 하나 더 돌려 `seed42.json`의 새 칸 `ruler_summary_line`과 견준다(답과 정책의 결정론이 빌드를 넘어 지켜지는지).

## 7. 목표의 정리 (결정 요청)

문서가 서로 다르다: 종료 조건 ⓑ '첫 600틱 결정 ≥ 15'와 비전 '300~600틱마다 결정 1'·'10분(≈6,000틱)'(×10 기준). 잰 값은 600틱까지 4~5, 6,000틱까지 중앙값 19(범위 8~37)다. 600틱에 15를 채우려면 40틱마다 카드가 와야 하고, 그것은 A2의 카드 설계(막 선 조건·주기 슬롯·대기 중 버림)와 맞지 않는다.

권장: ⓑ를 **'커맨드렛 30판(`-TellAll=0 -Answer=1 -Build=1`): 첫 6,000틱의 결정 중앙값 ≥ 15, 첫 600틱의 말해진 줄 중앙값 ≥ 20'**으로 고친다(비전의 '첫 600틱 결정 ≥ 15'와 `docs/40`의 'T1 결정 ≥ 1/30틱'도 같은 말로). 비전의 '말해진 줄 25~40'은 Phase 5의 목표로 그대로 둔다.

말해진 줄을 채우는 손잡이(로드맵 '빈 지도' 위험의 처방 — `FirstSightTick`·`SightLanesByTier[0]`·청원 밀도): **`SightLanesByTier` [1,2,4,6,10] → [2,3,4,6,10]**(첫 칸부터 이웃의 이웃까지 본다, 칸마다 지도가 넓어지는 것은 지킨다) + **`PetitionPeriodTicks` 600 → 300**(비전의 '300~600틱마다 결정 1'의 아래 끝, 첫 주기 카드가 틱 300). `FirstSightTick` 330('5:30 첫 접촉')은 그대로 — 보는 거리만으로 목표에 닿는다. 잰 값: 600틱 결정 5, 6,000틱 결정 19(8~37), 600틱 말해진 줄 24.5(14~44).

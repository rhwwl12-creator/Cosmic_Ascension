# 용어집 (옛 §15)

> 원문: guideline.md v0.8 §15 (2026-10-19 docs/ 재편으로 이관, 내용 무변경 — 원격의 Phase 3 꼬리 작업 반영분 포함). 표지 `(v0.8 — 단계 N부터)`·`(v0.7 — …)`·`Phase N`이 붙은 문장은 **예정**(아직 코드에 없음), 표지 없는 문장은 **현행 규칙**이다. 열린 물음은 `docs/60_DECISIONS/OPEN_QUESTIONS.md`, 확정 기록은 `docs/60_DECISIONS/DECISIONS_LOG.md`. 절 번호(§N)는 원문 그대로 두었다 — 위치는 `docs/SECTION_MAP.md`.

※ 같은 낱말의 두 뜻은 이렇게 고정한다: '칸' = Tier(거대 프로젝트의 자리는 늘 '건설 칸'·'대응 칸'으로 꾸며 쓴다 — 아래 '거대 프로젝트'), '칙령의 자리' = 한 백성이 함께 세울 수 있는 칙령의 수(화면의 낱말이고 설계 낱말은 '슬롯' — 프로젝트의 칸과 다른 것이다, B2), '우호의 자리' = 한 백성이 함께 우호로 대할 수 있는 백성의 수(칙령의 자리와 따로 센다, B3 — '자리'는 늘 무엇의 자리인지 꾸며 쓴다), '지킴' = 함대의 목표를 제 성계에 두는 일 / '지켜 냄' = 남의 공성이 끝에서 막힌 결과(B3 — 아래 '지킴 / 지켜 냄'), '쉼'(공성 뒤) = AI가 공성 뒤 적대를 열지 않는 동안(설계 낱말 — 안식 `Truth.Rest`와 다른 말, B3), '부르심' = 서막 끝의 소명 사건, '문턱' = T3(칸 이름) / `enc_threshold`(T5 카드), '정착률'은 '주장 만료율'로 바꿔 부른다. '도약'만 쓰면 공백기의 시간선 도약이다 — T3의 순간 이동 권능(방랑자의 이동, §5.9 — 설계 문서에 '도약' 권능으로 적혀 온 것)은 '도약'이라 부르지 않고 'T3의 순간 이동'으로 쓴다(게임 안의 이름은 그 권능이 오는 블록에서 정한다). '복귀' = 방랑자가 옛 백성의 왕좌로 돌아가는 일(B1), '귀환' = 회귀 교리의 제안(`enc_recurrence_return`).
